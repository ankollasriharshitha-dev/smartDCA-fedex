# SmartDCA – FedEx Hackathon

An AI-driven prototype to manage Debt Collection Agencies (DCAs)
using digital workflows and basic AI-based prioritization.

## Features
- Simple web UI for DCA dashboard
- Rule-based AI model for recovery prioritization
- Basic pipeline simulating case processing

## Tech Stack
- HTML, CSS (UI)
- Python (AI logic)
